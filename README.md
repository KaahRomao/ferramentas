# Painel de Ferramentas

Reuni conversores e calculadoras em uma página para praticar lógica, eventos do DOM e integração com API em JavaScript.

[Abra a demonstração](https://kaahromao.github.io/ferramentas/)

## Ferramentas

- Conversão entre real e dólar com cotação da AwesomeAPI.
- Conversão de temperatura, velocidade e massa.
- Calculadora de IMC e regra de três.
- Alternância entre temas claro e escuro.

## Rodar localmente

Clone o repositório e abra `index.html` no navegador. A cotação do dólar precisa de conexão à internet. Os outros cálculos rodam no navegador.
